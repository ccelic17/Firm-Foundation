## Getting Email Addresses (Hunter.io Workflow)

1. Go to **[hunter.io/email-finder](https://hunter.io/email-finder)**
2. Enter: First Name + Last Name + Company Domain (from table above)
3. Hunter verifies the email format against the company's mail server (MX check)
4. Save verified emails back into this table

**Common verified email formats by company:**
- Stryker: `firstname.lastname@stryker.com`
- Medtronic: `firstname.lastname@medtronic.com`
- ADP: `firstname.lastname@adp.com`
- Paychex: `firstname.lastname@paychex.com`
- Cintas: `firstname.lastname@cintas.com`
- Boston Scientific: `firstname.lastname@bsci.com`
- Allergan: `firstname.lastname@allergan.com`
